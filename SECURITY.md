# Política de segurança

## Versões suportadas

Correções de segurança serão priorizadas na versão publicada mais recente do projeto.

## Como relatar uma vulnerabilidade

Não abra uma issue pública para relatar uma vulnerabilidade. Envie uma mensagem privada aos mantenedores pelo canal de contato indicado no perfil do repositório.

Inclua, quando possível:

- descrição do problema;
- passos para reproduzi-lo;
- impacto potencial;
- versão ou commit afetado;
- evidências e uma sugestão de correção, se houver.

Responderemos assim que possível, confirmaremos o recebimento e combinaremos os próximos passos para validar e corrigir o problema.

Evite compartilhar publicamente dados pessoais, tokens, senhas ou credenciais durante o relato.
