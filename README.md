# Enterview

Plataforma open-source de estudos com base em flashcards, simulados para provas com pdf, roadmap para concursos e desafios.

> O projeto está em evolução. Sugestões, correções e contribuições são bem-vindas.

## Sobre

O Enterview é um ambiente flexível para transformar perguntas em sessões de estudo, preparação ou avaliação. A proposta é reunir criação de conteúdo, organização das sessões e acompanhamento do desempenho em uma única plataforma.

## Para que serve

- estudar e revisar conteúdos;
- montar simulados e listas de questões;
- preparar-se para concursos e provas;
- conduzir entrevistas técnicas ou comportamentais;
- criar avaliações, treinamentos e outros fluxos baseados em perguntas.

Consulte o [roadmap](ROADMAP.md) para conhecer a direção atual do projeto.

## Executando localmente

Os requisitos e comandos específicos dependem da configuração atual do projeto. Quando aplicável, copie o arquivo de ambiente de exemplo, instale as dependências e inicie o servidor de desenvolvimento:

```bash
cp .env.example .env
npm install
npm run dev
```

Se algum desses arquivos ou scripts não existir, use os comandos definidos no `package.json` e mantenha esta seção atualizada.
